工具一

Skill 体检：装之前先查一遍。

规范检查依据 agentskills.io/specification，安全扫描给出人工复核提示。

提示：在输入框内按 Ctrl/Cmd + Enter 也能开始体检。

报告会显示在这里。先粘贴 SKILL.md，或点「载入示例」看看报告长什么样。

计分：满分 100，严重 −25、高危 −20、警告/中危 −8、提示 −2。A ≥90，B ≥75，C ≥60，D <60；只要有严重或高危问题，等级最高为 C。

静态检查只能发现常见问题，干净结果不代表绝对安全；所有处理在你的浏览器内完成，内容不会上传。

工具二

中文 Skill 生成器：填空，得到合规的 SKILL.md。

右侧实时生成，可直接复制，或送去体检。

自动转为小写和连字符。规则：1–64 位，只用 a-z、0-9 和 -，不以 - 开头或结尾，不能有 --，与文件夹同名。

每条会接在「当用户……时使用」里，读得通就行。

为什么要体检：三个最常见的坑。

权限很大

Skill 能执行命令、读文件，装错等于给陌生人开了终端。

不被调用

description 写不好，Agent 根本不会调用。

直接拒收

名字不合规，很多平台直接拒收。

合规速查表：每个字段的要求。

依据 Agent Skills 开放标准。

常见问题

内容会上传吗？

不会，全部在浏览器本地运行。

支持哪些平台？

遵循 Agent Skills 开放标准的平台，如 Claude Code、Codex、Cursor、Gemini CLI，以及国内兼容 SKILL.md 的 Agent 平台。

体检通过就安全吗？

不一定，它只做静态检查，安装前仍建议看一遍脚本。

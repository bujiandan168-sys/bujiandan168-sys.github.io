# 抖音 / 视频号口播脚本

产出一条能直接拍、能直接剪的竖屏短视频脚本：钩子 → 铺垫 → 主体 → 高光 → 引导。

## 工作流程

```
- [ ] 1. 补齐输入（最多问 2 个问题）
- [ ] 2. 定「一句话主旨」+ 时长 + 唯一 CTA
- [ ] 3. 写 3 个钩子，选 1 个
- [ ] 4. 写口播全文，按字数校准时长
- [ ] 5. 拆分镜表
- [ ] 6. 出字幕稿
- [ ] 7. 自检（脚本 + 清单），修到通过
- [ ] 8. 按模板交付
```

### 1. 补齐输入

缺了会写错才问，最多 2 个，优先：**能不能真人出镜/有哪些可拍素材**（决定分镜是否可执行）、**要观众做的唯一动作**（关注/评论/到店/点购物车）。

未说明时用默认值：平台 = 抖音；时长 = 45 秒；真人口播 + 手机拍摄 + 少量产品/环境空镜；CTA = 评论。

### 2. 主旨与时长

- 一条视频只讲一件事，信息点 ≤3 个。
- 口播字数 = 时长（秒）× 4–5 字/秒（经验值，正常语速）。45 秒 ≈ 180–225 字，60 秒 ≈ 240–300 字。
- 时长分配：钩子 0–3 秒｜铺垫 10–15%｜主体 60–70%（每 5–8 秒一个信息点或画面变化）｜高光 5–10%｜CTA 最后 3–5 秒。

### 3. 钩子

写 3 个，标出推荐。每个钩子都必须同时有**画面动作**和**一句话**：
- 第一句 ≤15 字，第 1 秒就有动作或变化，不以「大家好我是…」开场。
- 钩子的承诺必须在视频里兑现，否则观众看完会觉得被骗、不互动。

默认用「结果前置」（先放结果画面 + 一句结论）。8 种钩子写法和各类视频的主体结构在 [references/hooks-and-structures.md](references/hooks-and-structures.md)，写带货/知识/门店类时读对应段落。

### 4. 口播全文

- 写「你」不写「用户」；短句；可以有语气词；数字用阿拉伯数字。
- 每个信息点 = 观点 + 例子/演示 + 一句可截屏的金句。
- 每段标注预计秒数和字数，总字数必须落在第 2 步算出的区间。

### 5. 分镜表

用 [assets/storyboard-template.md](assets/storyboard-template.md) 的表头。规则：每 2–4 秒切一次画面或景别，单镜头不说满 15 秒；每行「画面内容」写到拍摄者一看就知道拍什么（主体 + 动作 + 景别）。

### 6. 字幕稿

- 每行 ≤14 字，一屏最多 2 行，按语义断句。
- 每屏最多 1 处关键词花字。
- 字幕放画面中下部，避开右侧互动栏和底部文案区。
- 同时给一份 SRT 格式，方便导入剪映。

### 7. 自检（必须执行）

```bash
python3 scripts/check_copy.py --platform douyin --body-file <口播全文> --seconds <目标秒数>
```

检查语速（3.5–5 字/秒）、绝对化/医疗用语、联系方式。WARN 逐条处理；无 Python 时按「交付前清单」人工核对。

### 8. 交付模板

```markdown
## 视频信息
平台：…｜时长：…秒｜口播字数：…｜语速：…字/秒｜目标动作：…

## 钩子备选
1. 【画面】…【口播】…（推荐：<理由>）
2. …
3. …

## 口播全文
[0–3s｜钩子｜…字] …
[3–8s｜铺垫｜…字] …
…

## 分镜表
<按 assets/storyboard-template.md>

## 字幕稿（SRT）
1
00:00:00,000 --> 00:00:02,500
…

## 发布信息
标题：…｜话题：#… #… #…（3–5 个）｜封面字：…

## 拍摄提示（≤3 条）
- …
- 需用户补充：<【待补充】项；没有则写「无」>
```

## Gotchas / 常见坑

- **完播只是信号之一**：抖音官方「安全与信任中心」公开的推荐原理是预估用户的多种行为（看完、点赞、评论、分享、关注等）并按价值加权排序，平台称核心目标是「用户长期价值」。所以不要为了完播把视频剪到没信息量，也不要用与内容无关的悬念骗停留——前 3 秒留人，之后靠信息密度和兑现承诺留人。网上流传的「3 秒跳出率超过 X% 就停推」等阈值没有官方依据，不要写进交付物。
- **AI 内容要主动声明**：《人工智能生成合成内容标识办法》2025-09-01 起施行；抖音要求发布 AI 生成内容时在发布页主动添加 AI 标识，未声明的疑似内容会被平台加注提示。脚本里用到 AI 配音、数字人、AI 画面时，在「拍摄提示」里提醒用户勾选声明。
- **带货/探店附购买方式就要标「广告」**：《互联网广告管理办法》第九条——以体验分享、消费测评形式推销并附购物链接等购买方式的，须显著标明「广告」。
- **绝对化用语与疗效宣称**同样适用短视频口播和字幕（最、第一、全网最低；食品/化妆品不能说治疗、减肥）。详见 [references/ad-compliance-cn.md](references/ad-compliance-cn.md)，带货、门店、功效类脚本先读它。
- **价格/优惠要写条件和期限**（《广告法》第八条）：「到店报暗号送熨烫」要写清有效期、每人限几次。
- **背景音乐**用平台曲库或已授权音乐；画面里出现的他人肖像、他人门店需取得同意。
- **语速换算是经验值**（4–5 字/秒），不是平台规则；最终以用户实际试读为准。

## 交付前清单

- [ ] 口播字数在「时长 × 4–5」区间内
- [ ] 前 3 秒同时有画面动作和钩子句，承诺在后文兑现
- [ ] 分镜每行可执行，2–4 秒一切
- [ ] 只有 1 个主 CTA
- [ ] 字幕每行 ≤14 字，附 SRT
- [ ] 无绝对化用语、无疗效宣称；优惠写明条件与期限
- [ ] 带货附链接已提醒标「广告」；AI 素材已提醒声明
- [ ] 缺失素材用【待补充】标出

## 去 AI 味自检（交稿前过一遍）

- 删掉「首先/其次/综上所述/值得注意的是/赋能/打造」等套话，换成具体事实、数字或场景。
- 句长要有长有短，不要每段都三点并列、每句都对仗。
- 至少保留一处只有真人才会说的细节（亲身经历、具体价格、踩过的坑）。
- 没有依据的数据和夸张形容词一律删掉或标「待核实」。

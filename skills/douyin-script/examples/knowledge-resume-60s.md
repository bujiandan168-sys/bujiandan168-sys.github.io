# 示例：知识类 60 秒口播（简历第一行）

## 输入
> 帮我写个 60 秒抖音，讲「简历怎么改才有人回」，面向应届生，真人出镜，目标动作：评论。

## 口播全文（254 字 / 60 秒 = 4.2 字/秒）
你有没有发现，同一份简历，投出去十份，九份没回音？问题多半不在经历，在第一行。招聘的人一天要扫两百份简历，每份大概只看十来秒。所以第一行要直接写结果：把“负责社群运营”改成“三个月把社群从 300 人做到 2800 人”。第二个改法，删掉“熟练使用办公软件”这种谁都能写的话，换成你真做过的事，比如“用表格做了月度复盘，帮团队省下每周两小时”。第三个改法，一页就够，两页以内是上限。改完别急着投，先读给朋友听，听不懂的地方就是招聘的人会跳过的地方。你的简历第一行现在写的是什么？评论区贴出来，我挑几条帮你改。

## 自检输出
```
INFO 口播 250 字 / 60 秒 = 4.2 字/秒
结果：0 个 ERROR，0 个 WARN
```
（「第一行」「第一个」这类序数不再误报「第一」；「全网第一」仍会命中。）

## 要点
- 钩子：【画面】举着打印简历、指第一行【口播】“投十份，九份没回音”，承诺在第 3 句兑现。
- 数据（两百份、十来秒）是示意，实际发布前标【待核实】。
- 唯一 CTA：评论区贴第一行。

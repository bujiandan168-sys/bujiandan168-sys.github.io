# 英文 X 热帖 → 中文爆款帖

不是翻译，是**编译 + 再创作**：抓住原帖核心洞见，用中文读者熟悉的语境重讲，加上自己的观点，并清楚注明出处。

## 工作流程

```
- [ ] 1. 拿到原文（只有链接且打不开时，请用户粘贴原文）
- [ ] 2. 原帖拆解（交给用户确认，不发布）
- [ ] 3. 确定目标平台与形态
- [ ] 4. 本土化改写
- [ ] 5. 加出处声明
- [ ] 6. 自检（翻译腔 + 合规 + 字数），修到通过
- [ ] 7. 按模板交付
```

### 1. 拿到原文

用户只给链接时：能打开就读；打不开（X 常需登录）就请用户粘贴原文和作者 handle，**不要凭链接猜内容**。

### 2. 原帖拆解

- 作者是谁、什么背景（只写能从原文或用户提供信息确认的；不确定写「未知」）
- 核心观点（1 句）
- 支撑论据（3–5 条）
- 为什么会火（反常识 / 实用清单 / 个人故事 / 数据）
- 中文读者适配难点（文化背景、产品国内是否可用、术语）

用户已明确说「直接出稿」时，拆解与成稿一起交付。

### 3. 平台与形态

未说明时默认**即刻/微博单条长帖**。

| 平台 | 形态 | 建议长度 |
|---|---|---|
| 即刻 / 微博（默认） | 单条长帖 | 300–800 字 |
| X 中文串 | thread，每条 ≤280 加权字符（≈140 个汉字） | 5–12 条 |
| 小红书 | 图文笔记 → 交给 xiaohongshu-viral 的格式 | 标题 ≤20 字，正文 ≤1000 字 |
| 公众号 | 编译文章 → 交给 wechat-article 的格式 | 1500 字以上 |

X 中文串结构：

```
1/ 钩子：结论或反差 + 为什么值得看（注明「编译自 @xxx」）
2/ 背景：原作者是谁 / 上下文
3/ … N-2/ 每条一个要点：要点 + 一句解释 +（可选）本土例子
N-1/ 我的看法 / 放到国内怎么用
N/ 总结 + 互动问题 + 原帖链接
```

### 4. 本土化改写

- **钩子重写**，不直译开头：「I spent $50k learning this so you don't have to」→「一位美国创业者花几十万学费换来的 7 条教训，第 4 条国内老板尤其该看。」
- **术语**：首次出现给中文 + 英文原词，如「产品市场契合度（PMF）」。
- **替换不可用的例子**：国外工具/平台在国内不可用时，补国内对应方案并标「（编者注）」。
- **单位与货币**：美元附人民币约数并注明「按 X 汇率估算」；英制转公制。
- **区分声音**：用「我的看法：」「放到国内：」把编者观点和原作者观点明确分开。
- **至少 1 项增量**：个人观点、本土案例、补充数据、反方观点或实操步骤，原帖没有的。

### 5. 出处声明（固定格式，放开头或结尾）

```
来源：@原作者handle（原作者名）在 X 上的帖子，原文链接：<URL>
本文为编译 + 个人解读，非逐字翻译；观点以原文为准。
```

### 6. 自检

- 发 X 中文串时运行：`python3 scripts/x_weighted_len.py thread.txt`，任何一条超 280 就拆分或删字。
- 翻译腔清单：删多余「的/了/一个」；被动改主动；长定语拆短句；英文惯用语换中文说法；去掉「让我们……」；读出来像中国人在说话。
- 合规清单见下方「交付前清单」。

### 7. 交付模板

```markdown
## 原帖拆解（供确认）
…
## 改写稿（<平台>）
…
## 出处声明
…
## 增量说明
本稿新增了：…
## 发布建议
标题/话题/配图：…
```

## Gotchas / 常见坑

- **X 按加权字符计数**：上限 280，**每个汉字、全角标点、emoji 计 2**，每个链接固定计 23（X 官方开发文档）。所以一条纯中文推最多约 140 字，带链接还要再减 12 个汉字左右。别用普通字数统计判断能不能发。
- **不能整段搬运**：逐句全译后当自己的内容发是侵权风险最高的做法。成稿以自己的结构和表达为主，直接引用原文 ≤2 句并标为引用。原作者明确声明禁止转载/翻译时，提醒用户不要发布。
- **不歪曲原意**：可以精简、重组，不可把作者没说的话安到作者头上；有限定条件的观点保留限定条件。原帖数据不改数值，换算时注明是换算。
- **原帖图片/视频不直接搬**：引用链接或自制示意图。
- **敏感内容**：涉及政治、未经证实的传闻、个人隐私、投资建议时，不改写或加风险提示，并提醒用户自行判断。
- **发到小红书/公众号时**，对应平台的硬性规则同样适用（小红书标题 ≤20 字、正文 ≤1000 字、不留站外联系方式；公众号标题 ≤64 字、摘要 ≤120 字、禁止诱导分享）。

## 交付前清单

- [ ] 来源完整：作者显示名 + @handle + 原帖链接
- [ ] 无整段逐字翻译；直接引用 ≤2 句并标注
- [ ] 至少 1 项增量，且与原作者观点明确区分
- [ ] 原意未被扭曲；不确定的信息未被编造
- [ ] 符合目标平台长度；X 串每条 ≤280 加权字符
- [ ] 通过翻译腔清单

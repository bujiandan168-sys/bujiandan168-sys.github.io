# 示例：客户案例复盘（公众号长文骨架）

## 输入
> 帮我写篇公众号：我们给一家社区烘焙店做私域，三个月复购率从 12% 涨到 31%。读者是同行老板，目标动作：关注并领取「私域SOP」。

## 先交大纲（用户确认后再成稿）
1. 开头钩子：一家 80 平米小店，凭什么三个月复购翻了一倍多
2. 问题：以前只发优惠券，老客不回头
3. 三个动作：①取餐时加企微并打标签 ②每周固定一次「新品试吃」 ③生日/断买召回
4. 结果：复购 12%→31%【数据待客户确认】
5. 避坑：不要一上来拉大群
6. 结尾唯一动作：关注并回复「SOP」

## 5 个标题（≤64 字）
- 一家 80㎡烘焙店，三个月把复购率从 12% 做到 31%
- 别再发优惠券了：社区店老板的私域三步法
- （其余 3 个略）

## 摘要（≤120 字）
同样的店、同样的面包，只改了三个动作，老客回头率翻了一倍多。复盘全过程，附可直接照抄的话术。

## 自检

## 要点
- 数据为示意，发布前向客户核实并标【待核实】；不写「最有效」「第一」等极限词。

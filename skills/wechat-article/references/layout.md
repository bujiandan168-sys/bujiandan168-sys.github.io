# 排版规范（适配 135、秀米、壹伴或 Markdown 转换工具）

以下为常用默认值（经验值，非平台规则）：

- 正文字号 15–16px，行距 1.75–2，段间距 1 行，两端留白 8–16px
- 颜色：正文深灰（#333 左右），强调色 1 种 + 辅助色 1 种
- 小标题样式统一，编号 01 / 02 / 03
- 加粗用于关键句，每屏 ≤2 处；不要大段标红
- 图片：每 500–800 字 1 张，图下可加小字说明；用自有图或注明来源
- 长文开头可加「本文约 X 字，阅读需 X 分钟」（按 400 字/分钟估算）
- 封面图：大图常用 2.35:1（如 900×383px），小图 1:1
- Markdown 中用 `【配图：…】` 标注配图位置，粘贴到编辑器后替换

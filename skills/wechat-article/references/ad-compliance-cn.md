# 中国大陆广告合规速查（营销文案用）

在文案含有推销商品/服务的意图时读本文件（种草、带货、探店、品牌号、商单）。纯个人经验分享无推销意图时，仍建议遵守，但重点是第 1、2 条。

> 本文件只做写作自检，不构成法律意见。依据条文均为公开法规原文，核验日期 2026-11。

## 1. 绝对化用语（《广告法》第九条第三项）

法条原文：广告不得「使用“国家级”、“最高级”、“最佳”等用语」。市场监管总局《广告绝对化用语执法指南》（2023）明确范围包括「与其含义相同或者近似的其他用语」。

**默认替换表**（写稿时直接换掉，别留给用户判断）：

| 避免 | 改成 |
|---|---|
| 最好 / 最佳 / 最强 / 最便宜 | 我用过里比较顺手的 / 这个价位里性价比高 |
| 第一 / 销量第一 / No.1 | 写可核实的事实 + 时间 + 来源：「2026 年 9 月店内销量前三」 |
| 顶级 / 极品 / 王牌 / 首选 | 高配 / 招牌 / 我常回购 |
| 国家级 / 世界级 / 全网最低价 | 删掉，或改成具体价格与时间 |
| 100% / 绝对 / 永久 / 万能 | 大多数情况 / 长期使用下来 |

**例外（指南第五、六条）**：自我比较（「我们家 3 款里最轻的一款」）、可证实的时空顺序事实（「2019 年首家进驻 XX 商场」）、依法评定的奖项名称，可以使用，但必须能拿出证明；拿不出证明就按普通绝对化用语处理。

## 2. 医疗/功效用语（《广告法》第十七、十八条）

- 第十七条：除医疗、药品、医疗器械广告外，禁止其他任何广告涉及疾病治疗功能，不得使用医疗用语或易与药品、医疗器械混淆的用语。
  - 普通食品、化妆品、日用品、服务：不写「治疗、治愈、根治、消炎、杀菌（针对人体）、祛痘、祛斑、减肥、降血压、防癌」等。
  - 改写方向：描述**使用感受与客观参数**（「质地清爽、上脸不黏」），不描述疗效。
- 第十八条：保健食品广告不得断言功效/安全性，不得涉及疾病预防、治疗，不得与药品比较，不得用代言人推荐；须显著标明「本品不能代替药物」。

## 3. 广告可识别性（《广告法》第十四条 +《互联网广告管理办法》第九条）

《互联网广告管理办法》（2023-05-01 施行）第九条：通过知识介绍、体验分享、消费测评等形式推销商品或者服务，**并附加购物链接等购买方式的**，应当显著标明「广告」。

写作默认：
- 商单/品牌合作稿 → 在开头或结尾明确标注（平台的合作标识 + 文中「广告」或「品牌合作」字样）。
- 品牌号自己发 → 以品牌身份第一人称写，不伪装成素人。

## 4. 价格与赠品（《广告法》第八条）

表示价格、赠品、优惠时应准确、清楚：写明赠品品种、数量、期限和方式；限时价写明起止时间。

## 5. 数据与引用（《广告法》第十一条）

使用数据、统计、调查结果、引用语时应真实准确并**表明出处**；有适用范围和有效期的要写明。没有来源的数据 → 写成【待补充：数据+来源】，不要编。

## 6. AI 生成内容标识

《人工智能生成合成内容标识办法》自 2025-09-01 起施行。抖音、微信、小红书等平台均要求用户发布 AI 生成合成内容时主动声明（平台发布页有「内容由 AI 生成」类声明选项）。交付时提醒用户：AI 生成的图片、配音、虚拟人像发布前要勾选平台的 AI 声明。

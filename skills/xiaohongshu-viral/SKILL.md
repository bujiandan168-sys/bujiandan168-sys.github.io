# 小红书爆款笔记

产出一篇用户复制即可发布的笔记。目标是「搜得到、点得开、存得下、评得出」。

## 工作流程

复制此清单并逐项打勾：

```
- [ ] 1. 补齐输入（最多问 2 个问题）
- [ ] 2. 定选题 + 核心搜索词
- [ ] 3. 写 5 个标题（每个 ≤20 字）
- [ ] 4. 写封面字
- [ ] 5. 写正文（≤1000 字，默认 400–700 字）
- [ ] 6. 配标签
- [ ] 7. 自检（脚本 + 清单），修到通过
- [ ] 8. 按模板交付
```

### 1. 补齐输入

能从用户消息推断的就别问。只在缺了会写错时提问，最多 2 个，优先问：
- **素材真实度**：有没有真实体验、价格、数据、前后对比？——没有就不写「亲测」「实测」，缺口用【待补充：…】标出。
- **账号身份**：个人号还是品牌/门店号？——决定是否需要合作标注、能否用第一人称素人口吻。

其余信息用默认值：目标 = 收藏 + 评论；读者 = 会主动搜这个关键词的人；语气 = 第一人称、口语、具体。

### 2. 定选题

选题 = **人群 × 场景 × 痛点 × 结果**。先确定 1 个**核心搜索词**（用户会在搜索框里打的 2–6 个字，如「小户型收纳」「油皮秋冬面霜」），它必须出现在标题前半段、正文前 100 字和标签里。

默认选「清单型」或「避坑型」（收藏率通常最高）；用户给的是个人经历就用「经历型」。需要更多选题公式时读 [references/title-formulas.md](references/title-formulas.md)。

### 3. 标题

写 5 个，每个都必须：≤20 字（含标点和 emoji）、含核心搜索词、有数字或具体人群、正文能兑现。推荐其中 1 个并说明理由（一句话）。

### 4. 封面字

主标题 ≤12 字（大字），可选副标题 ≤10 字。给出封面类型建议：前后对比 / 清单拼图 / 大字报 / 真人出镜+字。

### 5. 正文

用这个骨架，默认 400–700 字（硬上限 1000 字，**标签也计入正文字数**，所以正文留出余量）：

```
【开头 1–2 行】亮结果或戳痛点，含核心搜索词
【我的情况】一句话身份/背景，建立可信度
【干货主体】1️⃣2️⃣3️⃣ 分点，每点 = 小标题 + 2–3 句 + 1 个具体细节（价格/时长/型号/地点）
【避坑/缺点】至少 1 条真实缺点或注意事项
【互动】一个具体到能回答的问题
```

写法：短句，每段 ≤3 行；每段 0–2 个 emoji；品牌号也要像人说话。互动问题要具体：❌「大家觉得呢」✅「你家客厅多大？评论区帮你看」。

### 6. 标签

5–8 个，按「大词 1–2 + 中词 2–3 + 长尾 2–3 + 地域/品牌 0–1」组合，第一个放核心搜索词。

### 7. 自检（必须执行）

有 Python 时运行：

```bash
python3 scripts/check_copy.py --platform xhs --title "<推荐标题>" --body-file <正文文件或 - >
```

脚本检查标题/正文长度、绝对化用语、医疗用语、手机号/微信号/链接/二维码。出现 ERROR 必须改；WARN 逐条判断。没有 Python 环境时，按下方「交付前清单」人工逐条核对。改完重新检查，直到无 ERROR。

```markdown

## 标题备选
1. …（推荐：<理由>）
2. …
3. …
4. …
5. …

## 封面
主：…　副：…　类型：…

## 正文
…

## 标签
#… #… #…

## 发布建议

- 首条评论（置顶补充信息）：…
- 需用户补充：<列出所有【待补充】项；没有则写「无」>
```

## Gotchas / 常见坑

- **标题硬上限 20 字，正文硬上限 1000 字**（小红书官方开发文档：title 最大 20 字符、content 最大 1000 字符，超出报错）。emoji 和标点都占字数；话题标签在发布页通常也计入正文字数，正文要留余量。
- **站外导流会被处罚**：正文、图片、评论、简介里不能出现手机号、微信号（含谐音「v信」「薇❤」）、二维码、外链、其他平台水印。小红书 2025-03-12 生效的《交易导流违规管理细则》可处以限流直至封号。要引导到店，用「定位」「店名」或平台官方组件，不写联系方式。
- **商业合作必须走蒲公英**：蒲公英是品牌与博主商业合作的官方渠道，合作笔记先审后发。不要帮用户把商单写成「纯素人自发分享」——社区公约要求亮明经营身份、不伪装素人。
- **绝对化用语**（最、第一、顶级、首选、国家级…）属于《广告法》第九条禁止情形；**非医疗产品不能写疗效**（祛痘、减肥、治愈…，《广告法》第十七条）。改写方向：描述体验和参数，不描述疗效。详见 [references/ad-compliance-cn.md](references/ad-compliance-cn.md)，凡是带推销意图的稿件都先读它。
- **不编造体验**：用户没给的价格、时长、效果数据一律写【待补充：…】，不要用「亲测有效」填空。
- **AI 生成的图片/真人形象**发布时要勾选平台 AI 内容声明（《人工智能生成合成内容标识办法》2025-09-01 施行）。

## 交付前清单

- [ ] 5 个标题都 ≤20 字，且含核心搜索词
- [ ] 正文 + 标签 ≤1000 字；开头 100 字内出现核心搜索词
- [ ] 至少 3 个具体细节、至少 1 条缺点/提醒
- [ ] 无联系方式、链接、二维码、站外平台名导流
- [ ] 无绝对化用语、无疗效宣称
- [ ] 商单/品牌号已标注合作身份
- [ ] 所有缺失信息用【待补充】标出并在「发布建议」列出

## 去 AI 味自检（交稿前过一遍）

- 删掉「首先/其次/综上所述/值得注意的是/赋能/打造」等套话，换成具体事实、数字或场景。
- 句长要有长有短，不要每段都三点并列、每句都对仗。
- 至少保留一处只有真人才会说的细节（亲身经历、具体价格、踩过的坑）。
- 没有依据的数据和夸张形容词一律删掉或标「待核实」。

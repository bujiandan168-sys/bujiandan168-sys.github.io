# 示例（5 个品类）

每个示例只给关键部件，用来对齐风格，不要照抄内容。

## 1. 门店引流（烘焙店，门店号）
- 核心搜索词：成都碱水包
- 标题：成都碱水包｜玉林巷子里周末要排队（16 字）
- 封面：主「玉林巷子里的碱水包」副「每天限量 80 个」
- 开头：本来只想买一个尝尝，结果打包了 6 个回家 🥨
- 引导到店：写「店名 + 玉林西路附近 + 点笔记定位」，不写电话和微信
- 互动：你在成都吃过印象最深的面包店是哪家？

## 2. 知识干货（个人号·设计师）
- 核心搜索词：PPT配色
- 标题：PPT配色不会？记住这3个公式就够了（18 字）
- 主体：1️⃣ 同色系深浅 2️⃣ 主色 + 中性灰 3️⃣ 60-30-10 比例，每点配一张示意图
- 互动：想要哪个行业的配色模板？评论区告诉我

## 3. 好物清单（个人号·租房党）
- 核心搜索词：出租屋好物
- 标题：出租屋好物｜月薪5k这7件让我不想出门（19 字）
- 每件：价格区间 + 解决什么问题 + 一个缺点
- 避坑：网红香薰机别买，噪音大还漏水

## 4. 经历分享（创业者）
- 核心搜索词：开奶茶店
- 标题：开奶茶店第8个月，说点没人告诉你的（17 字）
- 主体：选址、房租占比、淡旺季、最后悔的一笔投入（数据缺就写【待补充】）
- 互动：想开店的，有问题评论区问我

## 5. 品牌种草（护肤品牌号）
- 核心搜索词：油皮换季护肤
- 标题：油皮换季护肤顺序｜稳定期这样排（15 字）
- 写法：以品牌主理人第一人称，产品只在其中一步出现，开头注明品牌身份
- 合规：不写「祛痘」「治疗」「修复屏障」等功效断言，改为「质地清爽，换季期我自己在用」
- 若附购买链接或为商单：标注合作/广告

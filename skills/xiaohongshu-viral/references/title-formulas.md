# 选题与标题公式

## 选题类型（默认先用前两种）

| 类型 | 公式 | 例子 |
|---|---|---|
| 清单型 | N 个 + 场景 + 好物/方法 | 出租屋提升幸福感的 9 件小东西 |
| 避坑型 | 我踩过的 N 个坑 + 怎么避 | 小户型装修，这 6 个钱别省 |
| 对比型 | A vs B，实测差在哪 | 199 和 1999 的投影仪差在哪 |
| 教程型 | 零基础 + 几步 + 结果 | 3 步做出咖啡店同款拉花 |
| 反常识型 | 你以为…其实… | 越贵的面霜越不适合油皮？ |
| 经历型 | 身份 + 时间 + 变化 | 30 岁裸辞开店 1 年，真实流水 |

判断一个选题能不能做：
1. 搜索框里有人搜吗？（在小红书搜核心词，看下拉联想和结果数）
2. 有收藏价值吗？（读者会不会「先存着以后用」）
3. 能拍出图吗？（没有图的选题很难做封面）

## 标题公式（每个 ≤20 字）

| 公式 | 例子 |
|---|---|
| 数字 + 结果 | 1 个月瘦 6 斤，我只改了早餐 ← 注意：品牌/商品推广稿不要写减重效果 |
| 身份 + 痛点 | 新手妈妈｜夜奶不崩溃的 5 个办法 |
| 反差 | 花 3 万报的班，不如这 4 个免费网站 |
| 提问 | 为什么你拍的照片总是灰灰的？ |
| 限定场景 | 周末 2 天｜杭州小众路线不排队 |
| 结论前置 | 直接抄作业！敏感肌秋冬护肤顺序 |

## 标题自检
- 核心搜索词在前 10 个字内
- 有数字或具体人群
- 不含「最、第一、顶级、100%、根治」等
- 不是标题党：正文第一屏就能兑现
